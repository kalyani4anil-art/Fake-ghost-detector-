Project Description

The Fake Ghost Detector is a useless but entertaining electronic device that creates the illusion of detecting paranormal activity. Using an Arduino UNO, PIR motion sensor, MQ-2 gas sensor, 16×2 LCD, and LEDs, it displays dramatic ghost alerts whenever movement or unusual gas levels are detected.

It cannot actually detect ghosts—but it can definitely detect when someone is ready to get scared

The Problem (that doesn't exist)

People are constantly worried about invisible ghosts hiding in ordinary places, but nobody has invented a reliable way to detect them.

Our project solves this completely unnecessary problem by providing a device that confidently announces paranormal activity without any paranormal evidence.

The Solution (that nobody asked for)

We built a Fake Ghost Detector that uses a PIR sensor to detect movement and an MQ-2 gas sensor to detect unusual gas levels. When either sensor is triggered, the LCD displays funny paranormal messages and the LEDs flash dramatically.

The result is a completely unnecessary gadget that turns ordinary movement or gas detection into a paranormal emergency.

Implementation

For Software:

Installation

1. Install the Arduino IDE.
2. Connect the Arduino UNO using a USB cable.
3. Install the "LiquidCrystal" library if required.
4. Connect the components according to the circuit diagram.
5. Upload the program to the Arduino UNO.

Run

1. Power on the Arduino UNO.
2. The LCD displays “FAKE GHOST DETECTOR”.
3. The PIR sensor detects movement, or the MQ-2 detects unusual gas levels.
4. The system displays “GHOST DETECTED!” or another funny alert on the LCD.
5. LEDs flash to indicate the fake detection.
6. The device returns to standby mode after a short delay.
